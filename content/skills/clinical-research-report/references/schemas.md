# Workspace file schemas

## extracted.json

Written in Phase 0, one entry per result per panel. Do not deduplicate here; deduplication happens in the script.

```json
{
  "patient_context": {
    "age": 34,
    "sex_at_birth": "female",
    "medications": ["levothyroxine 75mcg", "sertraline 50mg"],
    "supplements": ["biotin 5000mcg", "vitamin D 2000IU"],
    "conditions": ["hypothyroidism"],
    "family_history": ["type 2 diabetes (mother)"],
    "preanalytical": {
      "fasting": "unknown",
      "draw_time": "morning",
      "recent_exercise": "none",
      "recent_illness": "URI two weeks prior",
      "biotin": true,
      "cycle_day": null
    }
  },
  "symptoms": [
    {"symptom": "fatigue", "onset": "6 months", "severity": "moderate", "pattern": "worse in afternoon"}
  ],
  "results": [
    {
      "analyte": "Glucose",
      "value": 101,
      "unit": "mg/dL",
      "ref_low": 70,
      "ref_high": 99,
      "flag": "H",
      "collection_date": "2025-02-01",
      "lab_name": "Quest",
      "panel_name": "Comprehensive Metabolic Panel",
      "comment": null
    }
  ],
  "report_level_notes": [
    {
      "collection_date": "2025-02-01",
      "specimen_quality": "no hemolysis noted",
      "pathologist_comment": "verbatim text of any interpretive comment"
    }
  ]
}
```

Field notes:
- `value` must be numeric. For results reported as `<0.1` or `>1000`, store the numeric bound and put the operator in `comment`.
- `flag` is what the lab printed, not your computation. Leave null if absent; the script computes its own.
- `collection_date` in ISO `YYYY-MM-DD`. Collection date, not report date.
- `lab_name` matters. It drives the cross-lab comparison warning.
- `comment` and `pathologist_comment` are frequently the most useful text on the page. Capture verbatim.

## normalized.json

Script output. Do not hand-edit. Contains:

- `results` — every result, unit-normalized, with computed `flag` and `critical`
- `trends` — per analyte: n, RCV, first/last, total percent change, `exceeds_rcv`, per-interval steps, `in_range_trending`, `cross_lab`
- `unique_analytes` / `n_unique_analytes` — the research queue basis
- `multiple_comparisons` — expected false flags vs observed, for the synthesis section
- `critical_values` — anything tripping a panic threshold
- `errors` — plausibility failures. **Nonempty means stop and re-read the PDF.** The script exits nonzero.

## queue.md

Generated by the script with `--queue`, then hand-extended with one checkbox per symptom. This is the resume point. Tick each box only after its `notes/` file is written.

## notes/*.md

Format in `research-protocol.md` section 6. One file per analyte and per symptom. These are the source of truth for report assembly; anything not in a notes file does not go in the report.
